![Spring Boot](https://img.shields.io/badge/-Spring%20Boot-6DB33F?style=flat-square&logo=spring-boot&logoColor=white) ![Vue3](https://img.shields.io/badge/-Vue3-grey?style=flat-square) ![MySQL](https://img.shields.io/badge/-MySQL-4479A1?style=flat-square&logo=mysql&logoColor=white) ![ECharts](https://img.shields.io/badge/-ECharts-grey?style=flat-square) 

## 项目介绍

校园树语是一个校园绿化生态管理平台，师生可以浏览校园内的树木信息，认养心仪的树木并记录巡护日志，同时支持互动社区交流养护心得，系统还集成了AI智能助手提供养护建议。

**功能模块**

- **树木认养**：浏览校园树木列表，按树种、位置、状态筛选，支持在线认养申请
- **巡护记录**：认养者定期巡护并提交巡护日志，记录树木生长状态
- **互动社区**：发布话题帖子，分类浏览（赏花攻略、认养心得、校园风光等），支持评论点赞
- **积分中心**：巡护签到获取积分，积分排行榜激励用户参与
- **AI养护助手**：集成阿里千问大模型，智能解答树木养护问题
- **校园动态**：管理员发布校园绿化公告通知
- **管理后台**：用户管理、树木管理、认养审批、巡护管理、公告管理、积分管理、巡护数据分析

**技术架构**

- **后端**：Spring Boot 2.6.13 + Spring Data JPA + MySQL 8.0 + Session认证
- **前端**：Vue 3.5 + Vue Router 4 + Vite 8 + ECharts 6 + Axios
- **数据库**：MySQL 8.0
